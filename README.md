# Campus Customs Multi-Agent Operations: MGT 409 Homework 5

Everything is in **[`hw5/`](hw5/)**: an MCP server over the shop database, a FastAPI backend with a five-agent PydanticAI team (`gpt-6-luna` via Portkey), and a React dashboard where a human watches the agents and approves every payment.

- How to set up, run, and reset: [`hw5/README.md`](hw5/README.md)
- How it works: [`hw5/output/harness.md`](hw5/output/harness.md)
- The graded run (Expected vs. Actual, Cash, Reflection): [`hw5/output/desk_tickets.html`](hw5/output/desk_tickets.html)

Both database files are included under `hw5/data/`. The real `.env` is not; copy `hw5/.env.example` to `hw5/.env` and add your key.
